# QuantAgent 신뢰성 재수립 WBS 초안

## 계획 전제

- 이 WBS는 구현 계획이다. 코드나 배포가 완료됐다는 뜻이 아니다.
- 달력 날짜와 실명 배정은 `quantagent-production-capacity-matrix.md`의 사람 결정 입력이 채워진 뒤에만 확정한다. 지금은 `Wave`와 각 역할의 큐 순번만 사용한다.
- 모든 행은 하나의 의도된 커밋이다. P0는 코드 변경, 자동 검증 출력, 증적 URI, 승인자가 모두 있어야 완료다.
- `P0`는 출시를 막는 작업이다. `P1`은 P0가 닫힌 뒤에만 시작한다.

## 공통 완료 조건

각 행의 증적은 `commit:<hash> | command:<명령> | output:<저장 위치> | reviewer:<이름>` 형식이다. failure route 작업은 API 상태·사용자 문구·다음 행동·추천 차단·금지 노출을 동시에 검사한다.
