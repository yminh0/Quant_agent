# QuantAgent 용량·역량 매트릭스

## 현재 결정

2026-08-24 요청자(PM 대리)의 승인으로, WBS에 이미 기록된 실명 owner·backup 조합을 이번 8/31 목표의 **계획상 배정**으로 확정했다. 이는 개인 고용계약·초과근무 또는 운영 배포 권한을 새로 부여하는 결정은 아니다.

계획 용량은 8/24~8/31의 달력일 기준 인당 최대 64시간(8시간/일), 동시 쓰기 작업 최대 WIP 1로 둔다. reviewer의 읽기 전용 검토는 별도 reviewer slot으로 기록하며 구현 WIP에는 합산하지 않는다.

## 8/31 용량 예외와 운영 규칙

- 재기준화 시점(2026-08-24)의 미완료 WBS는 112건, 739시간이다. 위 계획 용량은 총 320시간이므로 419시간의 부족분이 있다.
- 따라서 8/31은 **모든 행의 목표 종료일**이지, 739시간 전체의 실행 가능 약속이 아니다. P0 release gate를 먼저 처리하고 P1/P2는 risk-accepted target으로만 표시한다.
- primary가 이미 동시 쓰기 작업 1개를 갖고 있으면 backup으로 handoff하거나, 행을 `대기`로 되돌린다. 같은 lock을 가진 두 구현 행을 병렬로 열지 않는다.
- release, 개인정보·보존, production data, 배포/rollback은 primary 단독 완료로 전이하지 않는다. 별도 reviewer 기록이 필요하다.

이 결정은 `PM-CAP-01`의 사람 결정 blocker를 해소한다. 다만 부족분을 숨기지 않으며, 8/31 이후 실행 가능 일정은 별도 재산정한다.
