# 읽기 전용 리포트 보관 정책 결정 기록

## 상태

2026-08-24 요청자(PM 대리)가 아래 정책을 승인했다. 이 결정은 `OD-REP-01`의 제품 정책 결정이며, 법령·계약·소송보존 의무가 더 긴 기간을 요구하는 경우 그 의무가 우선한다.

## 적용 범위

- 대상: 과거 전략 검증 리포트와 그 화면에 표시되는 재현·지표 근거
- 제외: 새 분석 실행, 투자 추천, 신규 리포트 생성
- 원칙: 보관된 리포트는 현재 추천이 아니라 과거 검증 기록으로만 표시한다.

## 승인할 항목

| 항목 | 선택 또는 값 | 적용 조건 |
|---|---|---|
| 보관 기간 | immutable report snapshot과 첨부 증적은 생성일부터 90일 | 법령·계약·legal hold가 있으면 해당 보존기간을 우선한다. |
| 만료 뒤 처리 | 본문·첨부·캐시·백업의 식별 가능 데이터를 삭제한다. 최소 감사 tombstone만 남긴다. | 삭제 불가 저장소는 접근불가 상태로 격리하고 다음 정리 주기에 삭제한다. |
| 열람 권한 | 인증된 report owner 및 최소권한 운영 역할만 열람한다. 공개 링크는 허용하지 않는다. | 지원 목적 열람도 audit event를 남긴다. |
| 표시 제한 | raw prompt, 계정/개인 식별자, credential, 내부 host·trace·운영 메타데이터는 표시·다운로드에서 마스킹한다. | pseudonymisation만으로 보존기한을 연장하지 않는다. |
| 이용자 안내 | 고정 | 읽기 전용, 기준 시점, 검증 범위, 제한 사항을 표시한다. |
| 감사 기록 | viewer/action/time/result와 삭제·hold 결과를 365일 보관한다. | 감사 로그에도 raw prompt·credential·불필요한 PII를 저장하지 않는다. |

## 운영 절차

1. 저장 시 `expires_at = created_at + 90일`을 부여한다.
2. 만료 전 자동 job이 삭제 후보를 표시하고, legal hold가 없으면 본문·첨부·캐시·백업의 식별 가능 데이터를 삭제한다.
3. 월 1회 보존 일정과 실제 삭제 결과를 검토한다. 기간을 연장하려면 목적·법적 근거·새 만료일을 별도 승인한다.
4. 법령·계약·분쟁 보존이 필요하면 legal hold ID, 범위, 만료 검토일을 기록한다. hold 해제 후 다음 정리 주기에 삭제한다.

정책 근거: 보존기간은 목적에 맞게 문서화하고, 더 이상 필요하지 않은 식별 가능 정보는 삭제 또는 익명화해야 한다는 [ICO storage limitation guidance](https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/data-protection-principles/a-guide-to-the-data-protection-principles/storage-limitation/)를 따른다. 이 문서는 법률 자문이 아니다.

## WBS 반영 조건

이 승인 기록으로 `OD-REP-01`은 정책 결정 범위에서 완료할 수 있다. 이후 `OD-REP-02`는 이 보관 기간, 권한, 표시 제한을 코드와 브라우저 증적으로 다시 확인해야 하며, 그 검증이 완료되기 전에는 운영 적용 완료라고 주장하지 않는다.
