## 7. 재현 절차

모든 Git 명령은 branch tip 대신 full SHA를 사용한다. 로컬 절대경로는 사용하지 않는다.

### 재현 전제

- Windows
- Python `3.12.5`
- disposable clone/worktree 안에 프로젝트 의존성이 설치된 repository-local `.venv`가 준비되어 있어야 한다.
- `.venv` 생성·의존성 설치 과정은 이번 QA evidence의 검증 범위에 포함하지 않는다.

### 재현 순서

1. disposable clone 또는 전용 worktree에서 tested SHA를 detached checkout한다.

   ```text

   cd <disposable-path>
   ```

2. 해당 worktree에 repository-local `.venv`가 준비됐는지 확인한다(§재현 전제 참조).
3. subject ancestry를 확인한다: `git merge-base --is-ancestor e1b8902a446bcc97be4f38ee0491515ef2e73767 476b7b64ac545dad0fc8fdbc644669007d35c232` → `true`
