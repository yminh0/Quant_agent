## Acceptance-axis coverage

Both axes are covered, and covered across both input shapes, by a single parameterized
test:

```python
@pytest.mark.parametrize("l4_evidence", [None, []])
def test_empty_l4_evidence_does_not_fall_back_to_fixture_evidence(l4_evidence) -> None:
```

`ai/tests/test_signal.py`

| Axis | Covered | Assertion |
|---|---|---|
| provenance absent for `None` | yes | `decision.l4_evidence == []` under `l4_evidence=None` — no fixture evidence is substituted |
| provenance absent for empty | yes | same assertion under `l4_evidence=[]` |
| 추천 0개 for `None` | yes | `signal["action"] == "NO_RECOMMENDATION"` and `risk["signal"]["action"] == "NO_RECOMMENDATION"` |
| 추천 0개 for empty | yes | same assertions |

The test also drives the full `signal_node` → `risk_manager_node` sequence rather than the
decision builder alone, so the absence of a recommendation is checked after the risk stage
rather than only at the point of construction. That matters for this row: the risk of a
partially covered axis here is a downstream node re-introducing a recommendation from
metrics that survived, and this test rules that out for the shapes it covers.

The parametrization is what makes the row's `None`·empty wording literally met. A single
non-parameterized case would have left one of the two shapes unproven.
