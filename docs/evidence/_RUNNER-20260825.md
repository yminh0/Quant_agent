## 왜 새 기준선인가

`origin`이 `sj0618/Qaunt_agent`에서 `sj0618/Quant_agent`로 옮겨졌다. 새 `main`
(`470d33e`, "Initial snapshot migrated from Qaunt_agent")은 이전 히스토리와 **공통 조상이
없는 orphan 스냅샷**이다. tree는 이전 `main`과 같은 `4b4f0f9`이므로 코드 내용은 이동하지
않았고, 커밋 그래프만 새로 시작했다.

그 orphan 전환이 이 러너가 발견한 결함 두 건의 직접 원인이다. preflight는 모든 증적 SHA가
`HEAD`의 조상일 것을 요구하는데(`assertReachableCommit`), 이전 히스토리에 고정된 SHA는
새 root 위에서 더 이상 조상이 아니다.

## 어떤 소스가 실제로 import 됐는가
